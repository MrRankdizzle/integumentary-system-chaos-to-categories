# Chaos to Categories: Integumentary System

A vocabulary review game for Human Anatomy & Physiology at Little Chute High School, built from the "From Chaos to Categories" slide activity.

Students sort 76 integumentary system terms across 5 boards in two modes:

- Guided Sort: category names are shown. Drag (or tap) terms into their boxes, then check.
- Chaos Mode: category names are hidden, Connections-style. Find the groups with 4 mistakes allowed.

Stars are saved in each student's own browser (localStorage). No accounts, no server.

## Files

- `index.html` is the whole app (HTML, CSS, and JavaScript in one file). Board content lives in the `BOARDS` array near the top of the script.
- `favicon.svg` is the tab icon.

## Deploy

Static site. Vercel serves `index.html` from the repo root with no build step; every push to `main` redeploys.
